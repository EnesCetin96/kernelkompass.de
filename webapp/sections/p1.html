Managing Files in Linux

Linux'ta Dosya Yönetimi

Dateiverwaltung unter Linux

Purpose: understand what Linux is, how the shell fits into the system, and learn the core commands to view, search, and manage files and their contents.

Amaç: Linux'un ne olduğunu, shell'in sistemin neresinde durduğunu anlamak ve dosyaları görüntülemek, aramak, içeriklerini yönetmek için temel komutları öğrenmek.

Zweck: verstehen, was Linux ist und wie die Shell in das System eingebettet ist, und die wichtigsten Befehle lernen, um Dateien und ihre Inhalte anzuzeigen, zu durchsuchen und zu verwalten.

kavram What is Linux? — Linux nedir?— Was ist Linux?

Linux is a free, open-source operating system — an alternative to Windows and macOS. "Open-source" means anyone can read, modify, and redistribute its source code.

TRLinux, ücretsiz ve açık kaynaklı bir işletim sistemidir — Windows ve macOS'a bir alternatiftir. "Açık kaynak" demek, kaynak kodunu isteyen herkesin okuyabileceği, değiştirebileceği ve yeniden dağıtabileceği anlamına gelir.

DELinux ist ein kostenloses, quelloffenes Betriebssystem — eine Alternative zu Windows und macOS. "Open-Source" bedeutet, dass jeder den Quellcode lesen, verändern und weiterverbreiten kann.

USER ↔ Shell ↔ Kernel ↔ Hardware — the shell is your only door into the system

TRSen komut yazdığında (örn. ls), bunu Shell alır, işletim sisteminin çekirdeği olan Kernel'e iletir, o da donanımla konuşup sonucu geri Shell üzerinden sana ekranda gösterir. Shell hem komut satırı yorumlayıcısı hem de bir programlama dilidir (Bash = "Bourne Again SHell").

DEWenn du einen Befehl eingibst (z. B. ls), nimmt die Shell ihn entgegen und leitet ihn an den Kernel weiter, den Kern des Betriebssystems. Dieser kommuniziert mit der Hardware und gibt das Ergebnis über die Shell auf deinem Bildschirm aus. Die Shell ist sowohl ein Kommandozeilen-Interpreter als auch eine Programmiersprache (Bash = "Bourne Again SHell").

Prompt sonundaki işaret önemlidir: $ normal kullanıcı demektir, # ise root / süper kullanıcı (yönetici) olduğun anlamına gelir.

Das Zeichen am Ende der Eingabeaufforderung ist wichtig: $ bedeutet normaler Benutzer, # bedeutet, dass du root/Superuser (Administrator) bist.

link Hard & Symbolic Links — Sabit ve sembolik bağlantılar— Harte & symbolische Links

A link lets one file appear under multiple names. Every file's data is stored in an inode (an internal record with a number); a hard link is a second name pointing at the same inode, while a symbolic link (symlink) is a small separate file that merely stores a path to the target — like a Windows shortcut.

TRBir bağlantı (link), tek bir dosyanın birden fazla isimle görünmesini sağlar. Her dosyanın verisi bir inode'da (numaralı bir iç kayıt) tutulur; hard link, aynı inode'u gösteren ikinci bir isimdir; sembolik link (symlink) ise hedefe giden yolu saklayan küçük, ayrı bir dosyadır — Windows kısayolu gibi.

DEEin Link lässt eine Datei unter mehreren Namen erscheinen. wildcard Wildcards (Globbing) — Joker karakterler— Platzhalter (Globbing)

Wildcards let one pattern select many files at once. The shell expands the pattern before the command runs — rm *.log becomes rm a.log b.log c.log automatically.

TRJoker karakterler, tek bir desenle birden çok dosyayı aynı anda seçmeni sağlar. Shell, deseni komut çalışmadan önce genişletir — rm *.log otomatik olarak rm a.log b.log c.log haline gelir.

DEPlatzhalter lassen ein Muster viele Dateien auf einmal auswählen. Die Shell expandiert das Muster, bevor der Befehl läuft — aus rm *.log wird automatisch rm a.log b.log c.log.

görüntüle Viewing Large Files Safely — Büyük dosyaları güvenle görüntüleme— Große Dateien sicher ansehen

cat dumps the whole file — fine for five lines, terrible for a 100 MB log. For big files use a pager or grab just the ends. And never trust a file extension: file inspects the actual content.

TRcat dosyanın tamamını basar — beş satır için iyi, 100 MB'lık bir log için berbat. Büyük dosyalar için bir sayfalayıcı kullan ya da sadece uçlarını al. Ve dosya uzantısına asla güvenme: file gerçek içeriğe bakar.

DEcat gibt die ganze Datei aus — gut für fünf Zeilen, furchtbar für ein 100 MB-Log. Nutze für große Dateien einen Pager oder greife nur die Enden ab. Und traue niemals einer Dateiendung: file untersucht den tatsächlichen Inhalt.
