rwx Anatomy of a Permission String — İzin dizesinin anatomisi— Anatomie einer Berechtigungszeichenkette

Every file has an owner and a group. ls -l shows a 10-character string: 1 for file type, then three groups of three (owner / group / others), each meaning read (r), write (w), execute (x).

TRHer dosyanın bir sahibi (owner) ve bir grubu vardır. ls -l komutu 10 karakterlik bir dize gösterir: ilk karakter dosya türü, sonra üçer üçer üç grup (sahip / grup / diğerleri), her biri okuma (r), yazma (w), çalıştırma (x) anlamına gelir.

DEJede Datei hat einen Eigentümer und eine Gruppe. ls -l zeigt eine 10-Zeichen-Kette: 1 Zeichen für den Dateityp, dann drei Dreiergruppen (Eigentümer / Gruppe / Andere), jede bedeutet Lesen (r), Schreiben (w), Ausführen (x).

-rwxr-xr-- örneği: sahip her şeyi yapabilir, grup okur+çalıştırır, diğerleri sadece okur
Beispiel -rwxr-xr--: Eigentümer kann alles, Gruppe liest+führt aus, Andere lesen nur

💡 Tip: Without x permission on a directory, you can't go INTO it (can't cd) — r only lists file names but you can't enter.
💡 İpucu: Bir dizinde x izni olmadan, o dizinin İÇİNE giremezsin (cd yapamazsın) — r sadece dosya isimlerini listeler ama içine giremezsin.
💡 Hinweis: Ohne x-Berechtigung auf ein Verzeichnis kannst du nicht HINEIN (kein cd) — r listet nur die Dateinamen auf, aber du kannst nicht hineingehen.

chown Copying & Ownership — Kopyalama ve sahiplik— Kopieren und Eigentümerschaft

cp alone does NOT preserve original permissions — use cp -p to keep them.

TRTek başına cp orijinal izinleri KORUMAZ — izinleri korumak için cp -p kullan.

DEcp allein bewahrt die ursprünglichen Berechtigungen NICHT — verwende cp -p, um sie zu behalten.

TERMİNALDE ÇALIŞTIR
chmod 640 source.txt
cp source.txt copy1.txt      # izinler DEĞİŞİR (varsayılan umask'e göre)
cp -p source.txt copy2.txt   # izinler AYNI kalır
sudo chown user1:user2 dosya.txt   # sahibi user1, grubu user2 yap

alıştırma Quick Self-Check — Kendini test et— Selbsttest

Given -rwxr-xr-- owned by alice:developers — can someone outside the "developers" group execute this file? What can the group do?

TR-rwxr-xr-- iznine sahip, sahibi alice, grubu developers olan bir dosya düşün — "developers" grubu dışındaki biri bu dosyayı çalıştırabilir mi? Grup ne yapabilir? (Cevap: grup okuyup çalıştırabilir ama yazamaz; diğerleri sadece okuyabilir, çalıştıramaz.)

DEAngenommen -rwxr-xr--, Eigentümer alice:developers — kann jemand außerhalb der Gruppe "developers" diese Datei ausführen? Was darf die Gruppe? (Antwort: die Gruppe darf lesen und ausführen, aber nicht schreiben; Andere dürfen nur lesen, nicht ausführen.)

oktal Octal Anatomy: 4-2-1 — Oktal anatomi: 4-2-1— Oktal-Anatomie: 4-2-1

Each permission digit is a sum of three bit values: read=4, write=2, execute=1. Adding the ones you want gives every possible combination from 0 to 7.

TRHer izin hanesi üç bit değerinin toplamıdır: okuma=4, yazma=2, çalıştırma=1. İstediklerini toplaman 0'dan 7'ye kadar her olası kombinasyonu verir.

DEJede Berechtigungsziffer ist die Summe dreier Bitwerte: Lesen=4, Schreiben=2, Ausführen=1. Das Addieren der gewünschten Werte ergibt jede mögliche Kombination von 0 bis 7.

💡 Tip: Add the three digits' bits mentally — 7-5-0 reads as "owner gets everything, group can read+run, others get nothing."
💡 İpucu: Üç hanenin bitlerini zihinden topla — 7-5-0, "sahip her şeyi alır, grup okuyup çalıştırabilir, diğerleri hiçbir şey alamaz" diye okunur.
💡 Hinweis: Addiere die Bits der drei Ziffern im Kopf — 7-5-0 liest sich als "Eigentümer bekommt alles, Gruppe kann lesen+ausführen, Andere bekommen nichts."

chgrp Changing Group Ownership: chgrp — Grup sahipliğini değiştirme: chgrp— Gruppenzugehörigkeit ändern: chgrp

chgrp changes only the group of a file, leaving the owner untouched — useful when a file needs to be shared with a team without giving up ownership.

TRchgrp yalnızca bir dosyanın grubunu değiştirir, sahibine dokunmaz — bir dosyanın sahipliği bırakılmadan bir ekiple paylaşılması gerektiğinde kullanışlıdır.

DEchgrp ändert nur die Gruppe einer Datei, der Eigentümer bleibt unberührt — nützlich, wenn eine Datei mit einem Team geteilt werden soll, ohne den Eigentümer aufzugeben.

TERMİNALDE ÇALIŞTIR
touch rapor.txt
sudo groupadd analistler
sudo chgrp analistler rapor.txt   # sahip degismedi, grup analistler oldu
ls -l rapor.txt                   # grup sutununu kontrol et
💡 Tip: chown user:group file can do both jobs at once — you don't always need a separate chgrp call.
💡 İpucu: chown kullanici:grup dosya iki işi birden yapabilir — her zaman ayrı bir chgrp çağrısına ihtiyacın olmayabilir.
💡 Hinweis: chown benutzer:gruppe datei kann beide Aufgaben auf einmal erledigen — du brauchst nicht immer einen separaten chgrp-Aufruf.

özel Special Bits: SUID, SGID, Sticky — Özel bitler: SUID, SGID, Sticky— Spezielle Bits: SUID, SGID, Sticky

Beyond rwx, three special bits change how a file or directory behaves, set with a leading fourth digit in chmod.

TRrwx'in ötesinde, üç özel bit bir dosya veya dizinin davranışını değiştirir; chmod'da baştaki dördüncü haneyle ayarlanır.

DEÜber rwx hinaus verändern drei spezielle Bits, wie sich eine Datei oder ein Verzeichnis verhält — gesetzt mit einer vierten, führenden Ziffer in chmod.

GERÇEK LINUX'TA — SİMÜLASYONDA YOK
chmod 4755 /usr/bin/passwd   # SUID: her kullanici kendi sifresini degistirebilir
chmod 2775 /shared/proje     # SGID: klasordeki yeni dosyalar proje grubunu alir
chmod 1777 /tmp              # Sticky: herkes yazar ama sadece sahip siler
💡 Tip: /tmp on a real Linux system already has the sticky bit set — that's exactly why one user's temp files are safe from another user's cleanup script.
💡 İpucu: Gerçek bir Linux sisteminde /tmp'de sticky bit zaten ayarlıdır — bir kullanıcının geçici dosyalarının başka bir kullanıcının temizlik scriptinden güvende olmasının nedeni tam olarak budur.
💡 Hinweis: Auf einem echten Linux-System ist das Sticky-Bit für /tmp bereits gesetzt — genau deshalb sind die temporären Dateien eines Benutzers vor dem Aufräum-Skript eines anderen sicher.

umask Default Permissions: umask — Varsayılan izinler: umask— Standardberechtigungen: umask

umask is a mask subtracted from the maximum default permissions (666 for files, 777 for directories) every time a new file or folder is created.

TRumask, her yeni dosya veya klasör oluşturulduğunda maksimum varsayılan izinlerden (dosyalar için 666, dizinler için 777) çıkarılan bir maskedir.

DEumask ist eine Maske, die bei jeder neuen Datei oder jedem neuen Ordner von den maximalen Standardberechtigungen (666 für Dateien, 777 für Verzeichnisse) abgezogen wird.

GERÇEK LINUX'TA — SİMÜLASYONDA YOK
umask               # mevcut maskeyi goster (cogu dagitimda varsayilan 022)
umask 077           # bu oturumdaki yeni dosyalari daha kisitli yap
touch gizli.txt
ls -l gizli.txt     # -rw------- olmali (666 - 077 = 600)
💡 Tip: umask never adds the execute bit to a plain file (that's why files default to 644, not 666-minus-mask-with-x) — directories need x to be enterable, so they get it by default.
💡 İpucu: umask düz bir dosyaya asla çalıştırma bitini eklemez (dosyaların varsayılan olarak 666 eksi maske ile x almadan 644 olmasının nedeni budur) — dizinlerin girilebilir olması için x'e ihtiyacı vardır, bu yüzden varsayılan olarak alırlar.
💡 Hinweis: umask fügt einer einfachen Datei nie das Ausführungsbit hinzu (deshalb sind Dateien standardmäßig 644, nicht 666 minus Maske mit x) — Verzeichnisse brauchen x, um betretbar zu sein, deshalb erhalten sie es standardmäßig.
