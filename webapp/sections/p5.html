i/o stdin, stdout, stderr — Standart giriş/çıkış/hata— Standard-Ein-/Ausgabe/Fehler

Every program has three standard streams: input coming in, normal output going out, and error messages going out separately.

TRHer programın üç standart "kanalı" (stream) vardır: içeri giren veri, normal çıktı, ve ayrı olarak giden hata mesajları.

DEJedes Programm hat drei Standard-"Kanäle" (Streams): eingehende Daten, normale Ausgabe und separat ausgehende Fehlermeldungen.

stdin comes in, stdout carries normal output, stderr carries errors separately
stdin girer, stdout normal çıktıyı, stderr hataları ayrı taşır
stdin kommt herein, stdout trägt die normale Ausgabe, stderr trägt Fehler separat

pipe The Pipe | — Boru operatörü— Der Pipe-Operator

A pipe sends the stdout of one command directly into the stdin of the next — this is how you chain small tools into powerful one-liners.

TRPipe (boru), bir komutun çıktısını doğrudan bir sonraki komutun girdisine bağlar — küçük araçları zincirleyerek güçlü tek satırlık komutlar yazmanı sağlar.

DEEine Pipe leitet die stdout-Ausgabe eines Befehls direkt in die stdin-Eingabe des nächsten — so verkettest du kleine Werkzeuge zu mächtigen Einzeilern.

TERMİNALDE ÇALIŞTIR
cat colors.txt | grep "blue"
#   ↑ çıktı        ↑ boru  ↑ filtre
# cat'in çıktısı, grep'in girdisi olur

💡 İpucu: && ve ||'yi birlikte kullanmak, tam bir if-else mantığı kurar: "başarılıysa bunu yap, değilse şunu yap".
💡 Hinweis: Die Verwendung von && und || zusammen baut eine vollständige if-else-Logik auf: "wenn erfolgreich, mache dies, sonst mache das".

yönlendirme Redirection: The Full Set — Yönlendirme: tam set— Umleitung: das komplette Set

Every command has three standard streams: stdin (0, input), stdout (1, normal output) and stderr (2, error output). Redirection operators re-plug these streams into files — and the crucial trick is that errors travel on their own channel.

TRHer komutun üç standart akışı vardır: stdin (0, girdi), stdout (1, normal çıktı) ve stderr (2, hata çıktısı). Yönlendirme operatörleri bu akışları dosyalara yeniden bağlar — kritik incelik, hataların kendi kanalında yolculuk etmesidir.

DEJeder Befehl hat drei Standard-Streams: stdin (0, Eingabe), stdout (1, normale Ausgabe) und stderr (2, Fehlerausgabe). Umleitungsoperatoren stöpseln diese Streams in Dateien um — der entscheidende Trick ist, dass Fehler auf ihrem eigenen Kanal reisen.

OperatorMeaning
>stdout to file, OVERWRITE
>>stdout to file, APPEND
<Feed a file in as stdin
2>stderr to file (errors only)
&>stdout AND stderr to the same file
2>&1Merge stderr into wherever stdout is going

<Bir dosyayı stdin olarak içeri ver

2>&1stderr'i, stdout nereye gidiyorsa oraya birleştir

cat gunluk.txt
GERÇEK LINUX'TA — SİMÜLASYONDA YOK
ls /yok 2> hatalar.txt             # yalnızca hata mesajını dosyaya yaz
komut > cikti.log 2>&1             # her şeyi tek log dosyasında topla
wc -l < welcome.txt                # dosyayı stdin'den ver
💡 Tip: cmd > file 2>&1 — order matters! First point stdout at the file, THEN merge stderr into it. Reversed, errors still go to the screen.
💡 İpucu: komut > dosya 2>&1 — sıra önemli! Önce stdout'u dosyaya yönelt, SONRA stderr'i ona birleştir. Ters yazarsan hatalar hâlâ ekrana gider.
💡 Hinweis: befehl > datei 2>&1 — die Reihenfolge zählt! Richte zuerst stdout auf die Datei, DANN mische stderr hinein. Umgekehrt gehen Fehler weiter auf den Bildschirm.

awk awk: Field Processing — awk ile alan işleme— Feldverarbeitung mit awk

Where cut slices columns, awk is a full mini-language for them: it splits every line into fields ($1, $2…), can filter rows by condition, and even do arithmetic across a whole file.

TRcut sütunları dilimlerken, awk onlar için tam bir mini dildir: her satırı alanlara böler ($1, $2…), satırları koşula göre süzebilir, hatta tüm dosya üzerinde aritmetik yapabilir.

DEWo cut Spalten schneidet, ist awk eine vollständige Mini-Sprache dafür: Es zerlegt jede Zeile in Felder ($1, $2…), kann Zeilen nach Bedingung filtern und sogar über eine ganze Datei hinweg rechnen.

GERÇEK LINUX'TA — SİMÜLASYONDA YOK
awk '{print $1}' isimler.txt            # her satırın ilk alanını bas
awk -F: '{print $1}' /etc/passwd        # -F: ayırıcıyı ':' yap → kullanıcı adları
awk '$3 > 50 {print $1}' notlar.txt     # 3. alanı 50'den büyük satırların 1. alanı
awk '{toplam += $2} END {print toplam}' satislar.txt   # 2. sütunun toplamı
💡 Tip: Rule of thumb: one column → cut; conditions or math → awk; find & replace → sed. The three together cover nearly all text surgery.
💡 İpucu: Pratik kural: tek sütun → cut; koşul veya matematik → awk; bul-değiştir → sed. Üçü birlikte neredeyse tüm metin ameliyatlarını kapsar.
💡 Hinweis: Faustregel: eine Spalte → cut; Bedingungen oder Mathematik → awk; Suchen & Ersetzen → sed. Zusammen decken die drei fast alle Text-Operationen ab.

durum Exit Status: $? — Çıkış durumu— Exit-Status

Every command finishes with a hidden number: its exit status. 0 means success, anything else means failure. The special variable $? holds the status of the last command — and it's exactly what &&, || and if look at behind the scenes.

TRHer komut gizli bir sayıyla biter: çıkış durumu (exit status). 0 başarı, diğer her şey başarısızlık demektir. Özel değişken $?, son komutun durumunu tutar — ve &&, || ile if'in perde arkasında baktığı şey tam olarak budur.

DEJeder Befehl endet mit einer versteckten Zahl: seinem Exit-Status. 0 bedeutet Erfolg, alles andere Misserfolg. Die Spezialvariable $? hält den Status des letzten Befehls — und genau darauf schauen &&, || und if hinter den Kulissen.

TERMİNALDE ÇALIŞTIR
true
echo $?              # → 0 (başarı)
false
echo $?              # → 1 (başarısızlık)
cat olmayan-dosya.txt
echo $?              # → 0 olmayan bir sayı: komut başarısız oldu
💡 Tip: In CI/CD pipelines this single number decides everything: a script that exits non-zero turns the whole pipeline red.
💡 İpucu: CI/CD pipeline'larında bu tek sayı her şeyi belirler: sıfırdan farklı bir kodla çıkan script, tüm pipeline'ı kırmızıya çevirir.
💡 Hinweis: In CI/CD-Pipelines entscheidet diese eine Zahl alles: Ein Skript, das mit einem Wert ungleich null endet, färbt die ganze Pipeline rot.
