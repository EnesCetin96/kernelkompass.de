while While & Until Loops — While ve Until döngüleri— While- und Until-Schleifen

while repeats as long as the condition is true. until is the opposite — it repeats until the condition becomes true (i.e. while it's false).

TRwhile, koşul doğru olduğu sürece tekrar eder. until ise tam tersi — koşul doğru olana kadar (yani yanlış olduğu sürece) tekrar eder.

DEwhile wiederholt sich, solange die Bedingung wahr ist. until ist das Gegenteil — es wiederholt sich, bis die Bedingung wahr wird (also solange sie falsch ist).

while [[ number -le 10 ]] do ... done — koşul yanlış olunca döngü durur
while [[ number -le 10 ]] do ... done — die Schleife stoppt, wenn die Bedingung falsch wird
while-loop.sh
#!/bin/bash
number=1
while [[ $number -le 10 ]]
do
  echo $number
  ((number++))
done
echo "Now, number is $number"

for For Loops & Select Loops — For ve Select döngüleri— For- und Select-Schleifen

for iterates over a fixed list of items. select builds an interactive numbered menu the user can choose from.

TRfor, sabit bir liste üzerinde döner. select ise kullanıcının seçebileceği numaralı, interaktif bir menü oluşturur.

DEfor durchläuft eine feste Liste von Elementen. select erstellt ein interaktives, nummeriertes Menü, aus dem der Benutzer wählen kann.

for-array.sh
#!/bin/bash
devops_tools=("docker" "kubernetes" "ansible" "terraform" "jenkins")

for tool in ${devops_tools[@]}
do
   echo $tool
done
select-loop.sh
#!/bin/bash
PS3="Select the operation: "
select operation in addition subtraction exit
do
  case $operation in
    addition) echo "toplama seçildi" ;;
    subtraction) echo "çıkarma seçildi" ;;
    exit) break ;;
    *) echo "Wrong choice..." ;;
  esac
done

func Functions — Fonksiyonlar— Funktionen

A function is reusable code that only runs when called. Arguments are passed the same way as script arguments ($1, $2...). Bash functions don't "return" a value like other languages — return just sets an exit status (0-255), captured in $?.

TRFonksiyon, sadece çağrıldığında çalışan, tekrar kullanılabilir koddur. Argümanlar script argümanlarıyla aynı şekilde geçilir ($1, $2...). Bash fonksiyonları diğer dillerdeki gibi bir "değer döndürmez" — return sadece bir çıkış durumu (0-255) belirler, bunu $? ile okursun.

DEEine Funktion ist wiederverwendbarer Code, der nur beim Aufruf ausgeführt wird. Argumente werden genauso übergeben wie Skriptargumente ($1, $2...). Bash-Funktionen "geben" keinen Wert wie in anderen Sprachen zurück — return setzt lediglich einen Exit-Status (0-255), den du mit $? ausliest.

functions.sh
#!/bin/bash
Welcome () {
    echo "Welcome to Linux Lessons $1 $2 $3"
    return 3
}

Welcome Joe Matt Timothy
echo $?    # → 3 (return ile belirlenen çıkış kodu)

scope Variable Scope: local — Değişken kapsamı— Variablengültigkeit

By default, ALL Bash variables are global — even ones declared inside a function. The local keyword restricts a variable to only exist inside that function.

TRVarsayılan olarak Bash'te TÜM değişkenler globaldir — bir fonksiyonun içinde tanımlansa bile. local anahtar kelimesi, bir değişkenin sadece o fonksiyonun içinde var olmasını sağlar.

DEStandardmäßig sind ALLE Bash-Variablen global — selbst wenn sie innerhalb einer Funktion deklariert werden. Das Schlüsselwort local beschränkt eine Variable darauf, nur innerhalb dieser Funktion zu existieren.

variables-scope.sh
#!/bin/bash
var1='global 1'
var2='global 2'

var_scope () {
  local var1='function 1'   # sadece fonksiyon içinde geçerli
  var2='function 2'         # local değil → GLOBAL var2'yi değiştirir!
}

var_scope
echo $var1   # → global 1 (değişmedi, local korudu)
echo $var2   # → function 2 (kalıcı olarak değişti!)
⚠️ Warning: If you forget to say local inside a function, that variable permanently changes the global variable — this is one of the most common script bugs.
⚠️ Dikkat: Fonksiyon içinde local demeyi unutursan, o değişken global değişkeni kalıcı olarak değiştirir — bu en sık yapılan script hatalarından biridir.
⚠️ Achtung: Wenn du innerhalb einer Funktion local zu schreiben vergisst, ändert diese Variable dauerhaft die globale Variable — das ist einer der häufigsten Skriptfehler.

aralık Range Expansion: {1..N} & C-Style for — Aralık genişletme: {1..N} ve C-stili for— Bereichs-Expansion: {1..N} und C-Stil-for

Looping over a fixed list works everywhere, but real bash also offers shortcuts for numeric ranges: brace expansion, C-style for (( )), and seq.

TRSabit bir liste üzerinde dönmek her yerde çalışır, ama gerçek bash sayısal aralıklar için de kısayollar sunar: süslü parantez genişletmesi, C-stili for (( )) ve seq.

DEDas Iterieren über eine feste Liste funktioniert überall, aber echtes Bash bietet auch Abkürzungen für numerische Bereiche: Klammer-Expansion, C-Stil-for (( )) und seq.

TERMİNALDE ÇALIŞTIR
for gun in Pazartesi Sali Carsamba
do
  echo "Bugun: $gun"       # sabit liste uzerinde for-in, her zaman calisir
done
GERÇEK LINUX'TA — SİMÜLASYONDA YOK
for i in {1..5}                 # brace expansion: 1 2 3 4 5
do
  echo $i
done

for (( i=0; i<5; i++ ))         # C-stili for dongusu
do
  echo $i
done

for i in $(seq 1 5)             # seq ile sayi listesi uretme
do
  echo $i
done
💡 Tip: {1..100} is easier to read than seq 1 100, but only brace expansion works when there's no external seq binary available (e.g. some minimal containers).
💡 İpucu: {1..100}, seq 1 100'den okunması daha kolaydır, ama harici seq ikili dosyası bulunmadığında (bazı minimal container'larda olduğu gibi) sadece brace expansion çalışır.
💡 Hinweis: {1..100} ist leichter zu lesen als seq 1 100, aber nur die Klammer-Expansion funktioniert, wenn kein externes seq-Binary verfügbar ist (z. B. in manchen minimalen Containern).

kontrol Nested Loop Control: break N / continue N — İç içe döngü kontrolü: break N / continue N— Verschachtelte Schleifensteuerung: break N / continue N

Plain break and continue affect only the innermost loop. Give them a number to jump out of (or skip an iteration of) an outer loop instead.

TRDüz break ve continue sadece en içteki döngüyü etkiler. Bunlara bir sayı vererek dıştaki bir döngüden çıkabilir (veya onun bir adımını atlayabilirsin).

DEEinfaches break und continue wirken nur auf die innerste Schleife. Gib ihnen eine Zahl, um stattdessen aus einer äußeren Schleife auszubrechen (oder eine ihrer Iterationen zu überspringen).

TERMİNALDE ÇALIŞTIR
for i in 1 2 3 4 5
do
  if [ $i -eq 3 ]
  then
    break              # duz break: dongudden tamamen cikar
  fi
  echo $i
done
GERÇEK LINUX'TA — SİMÜLASYONDA YOK
for i in 1 2 3
do
  for j in 1 2 3
  do
    if [ $j -eq 2 ]
    then
      break 2          # ic degil, DIS dongudden de cikar
    fi
    echo "$i-$j"
  done
done
💡 Tip: break 2 means "break out 2 levels" — count the loops from the innermost outward, not from the outside in.
💡 İpucu: break 2, "2 seviye dışarı çık" demektir — döngüleri en içteki dışa doğru say, dıştan içe doğru değil.
💡 Hinweis: break 2 bedeutet "2 Ebenen ausbrechen" — zähle die Schleifen von innen nach außen, nicht von außen nach innen.

dönüş "Returning" a Value: return vs echo Capture — Değer "döndürme": return vs echo yakalama— Einen Wert "zurückgeben": return vs echo-Erfassung

return only sets a numeric exit status (0-255), read via $?. To hand back a real string or number, have the function echo it and capture that output with $( ) from the caller.

TRreturn sadece sayısal bir çıkış durumu (0-255) belirler, $? ile okunur. Gerçek bir metin veya sayı geri vermek için fonksiyonun onu echo etmesini sağla ve çağıran tarafta bu çıktıyı $( ) ile yakala.

DEreturn setzt nur einen numerischen Exit-Status (0-255), gelesen über $?. Um einen echten String oder eine Zahl zurückzugeben, lass die Funktion ihn mit echo ausgeben und erfasse diese Ausgabe beim Aufrufer mit $( ).

TERMİNALDE ÇALIŞTIR
topla () {
  echo $(( $1 + $2 ))     # deger echo edilir, return degil
}

sonuc=$(topla 4 7)        # cagiran taraf ciktiyi $() ile yakalar
echo "Toplam: $sonuc"     # -> Toplam: 11
💡 Tip: Never try return $(( $1 + $2 )) for a big sum — return silently truncates anything above 255, while echo + capture keeps the exact value.
💡 İpucu: Büyük bir toplam için asla return $(( $1 + $2 )) deneme — return, 255'in üzerindeki her şeyi sessizce keser, echo + yakalama ise tam değeri korur.
💡 Hinweis: Versuche niemals return $(( $1 + $2 )) für eine große Summe — return schneidet alles über 255 stillschweigend ab, während echo + Erfassung den exakten Wert behält.
