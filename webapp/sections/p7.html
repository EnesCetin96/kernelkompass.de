elif If / Elif / Else & Nesting — Çoklu koşullar ve iç içe yapılar— Mehrfache Bedingungen und Verschachtelung

elif-statement.sh
#!/bin/bash
read -p "Input a number: " number

if [[ $number -eq 10 ]]
then
  echo "The number is equal to 10."
elif [[ $number -gt 10 ]]
then
  echo "The number is bigger than 10"
else
  echo "The number is smaller than 10"
fi

If statements can be nested — an if inside another if — to test multiple conditions in sequence.

TRIf ifadeleri iç içe (nested) yazılabilir — bir if'in içine başka bir if koyarak, sırayla birden fazla koşulu test edebilirsin.

DEIf-Anweisungen können verschachtelt werden — ein if innerhalb eines anderen if —, um mehrere Bedingungen nacheinander zu prüfen.

nested-if-statement.sh
#!/bin/bash
read -p "Input a number: " number

if [[ $number -gt 10 ]]
then
  echo "Number is bigger than 10"
  if (( $number % 2 == 1 ))
  then
    echo "And is an odd number."
  else
    echo "And is an even number"
  fi
else
  echo "It is not bigger than 10"
fi

case Case Statements — Case ifadesi (çoklu dallanma)— Case-Anweisung (Mehrfachverzweigung)

When you have many if/elif branches, a case statement is cleaner — it matches one variable against several possible values.

TRÇok fazla if/elif dalın varsa, case ifadesi daha temizdir — bir değişkeni birden fazla olası değerle eşleştirir.

DEWenn du viele if/elif-Zweige hast, ist eine case-Anweisung übersichtlicher — sie vergleicht eine Variable mit mehreren möglichen Werten.

case-statement.sh
#!/bin/bash
read -p "Select an operation (1-4): " operation

case $operation in
  "1")
     echo "addition"
     ;;
  "2")
     echo "subtraction"
     ;;
  *)
     echo "Wrong choice..."
     ;;
esac
💡 Tip: *) always goes last — it means "if none of the above matched", think of it like the "default" in other languages.
💡 İpucu: *) her zaman en sonda durur — "yukarıdakilerin hiçbiri eşleşmediyse" demektir, diğer dillerdeki "default" gibi düşün.
💡 Hinweis: *) steht immer am Ende — es bedeutet "wenn nichts oben Genanntes zutraf", denk daran wie an das "default" in anderen Sprachen.

üçtest test vs [ ] vs [[ ]] — test, [ ] ve [[ ]] karşılaştırması— Vergleich: test, [ ] und [[ ]]

All three are the same command in disguise: test cond, [ cond ], and [[ cond ]] evaluate the same conditions. [[ ]] is a bash keyword with extra safety: it doesn't split unquoted variables into words and supports pattern matching.

TRÜçü de aslında aynı komutun farklı kılıklarıdır: test kosul, [ kosul ] ve [[ kosul ]] aynı koşulları değerlendirir. [[ ]], bash'e özgü bir anahtar kelimedir ve ekstra güvenlik sağlar: tırnaksız değişkenleri kelimelere bölmez, desen (pattern) eşleştirmeyi destekler.

DEAlle drei sind eigentlich derselbe Befehl in unterschiedlicher Form: test bedingung, [ bedingung ] und [[ bedingung ]] werten dieselben Bedingungen aus. [[ ]] ist ein Bash-Schlüsselwort mit zusätzlicher Sicherheit: es zerlegt unquotierte Variablen nicht in Wörter und unterstützt Mustererkennung (Pattern Matching).

💡 Tip: In modern scripts, prefer [[ ]] over [ ] — it avoids classic quoting bugs when a variable is empty or contains spaces.
💡 İpucu: Modern scriptlerde [ ] yerine [[ ]] tercih et — bir değişken boşsa veya boşluk içeriyorsa oluşan klasik tırnak hatalarını önler.
💡 Hinweis: Bevorzuge in modernen Skripten [[ ]] gegenüber [ ] — es vermeidet klassische Quoting-Fehler, wenn eine Variable leer ist oder Leerzeichen enthält.

mantık Combining Conditions: -a/-o vs && / || — Koşulları birleştirme: -a/-o vs && / ||— Bedingungen kombinieren: -a/-o vs && / ||

Older scripts combine two tests inside one [ ] with -a (AND) / -o (OR). This is deprecated — modern style uses two separate [[ ]] tests joined by shell && / ||.

TREski scriptler tek bir [ ] içinde iki testi -a (VE) / -o (VEYA) ile birleştirir. Bu artık önerilmez — modern yaklaşım, iki ayrı [[ ]] testini shell'in && / ||'siyle birleştirmektir.

DEÄltere Skripte kombinieren zwei Tests innerhalb eines [ ] mit -a (UND) / -o (ODER). Das gilt als veraltet — moderner Stil verbindet zwei separate [[ ]]-Tests mit der Shell && / ||.
