Why free, and how is that protected?Neden ücretsiz, nasıl korunuyor?Warum kostenlos, und wie ist das geschützt?

Two different questions, two different answers.

İki farklı soru, iki farklı cevap.

Zwei verschiedene Fragen, zwei verschiedene Antworten.

To use: always free

Kullanman için: her zaman bedava

Zur Nutzung: immer kostenlos

Using KernelKompass never requires payment. No paywall, no trial period, no premium tier — it's been that way since day one and will stay that way.

KernelKompass'ı kullanmak hiçbir zaman ücret gerektirmez. Ödeme ekranı, deneme süresi ya da premium sürüm yok — ilk günden beri ve gelecekte de böyle kalacak.

Die Nutzung von KernelKompass erfordert nie eine Zahlung. Keine Bezahlschranke, keine Testphase, keine Premium-Stufe — das war seit dem ersten Tag so und bleibt so.

To prevent copying: source protected

Kopyalanmasın diye: kaynak korumalı

Gegen Kopieren: Quellcode geschützt

The code is protected under a license (PolyForm Noncommercial) that stops anyone from taking this project and selling it commercially. Not open source, but not restrictive either — just a guarantee that it stays free.

Kod, kimsenin bu projeyi alıp ticari olarak satmasını engelleyen bir lisansla (PolyForm Noncommercial) korunuyor. Açık kaynak değil ama kısıtlayıcı da değil — sadece "bedava kalsın" güvencesi.

Der Code ist durch eine Lizenz (PolyForm Noncommercial) geschützt, die verhindert, dass jemand dieses Projekt übernimmt und kommerziell verkauft. Nicht Open Source, aber auch nicht restriktiv — einfach eine Garantie, dass es kostenlos bleibt.

How to install it on your device?Cihazına nasıl kurulur?Wie installierst du es auf deinem Gerät?

KernelKompass is a PWA (Progressive Web App) — no app store needed, add it to your home screen or desktop in a few taps.

KernelKompass bir PWA (Progressive Web App) — hiçbir app store'a ihtiyacın yok, birkaç dokunuşla ana ekranına/masaüstüne eklenir.

KernelKompass ist eine PWA (Progressive Web App) — kein App Store nötig, füge sie mit wenigen Tipps zu deinem Startbildschirm oder Desktop hinzu.

  1. Open kernelkompass.de/webapp/ in Chrome, Edge, or another Chromium-based browser.
  2. Click the install icon (⊕ or computer icon) at the right end of the address bar.
  3. Click "Install" in the dialog that appears.
  4. KernelKompass now opens in its own window alongside your other apps — you can even access previous content while offline.
  1. kernelkompass.de/webapp/ adresini Chrome, Edge ya da başka bir Chromium tabanlı tarayıcıda aç.
  2. Adres çubuğunun sağ ucundaki yükleme simgesine (⊕ veya bilgisayar ikonu) tıkla.
  3. Açılan pencerede "Yükle" butonuna bas.
  4. KernelKompass artık diğer uygulamaların yanında, kendi penceresinde açılıyor — internetsizken bile önceki içeriğe erişebilirsin.
